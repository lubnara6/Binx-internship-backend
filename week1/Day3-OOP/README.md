# Day 3 - Object-Oriented Programming

## Overview

On Day 3, I created a small order domain to practice object-oriented programming in C#.

## What I Learned

- Created classes and objects.
- Used constructors and properties.
- Applied encapsulation using access modifiers.
- Created a record for immutable request data.
- Defined and implemented an interface.
- Demonstrated polymorphism.

## Project Structure

- `Order.cs` - Represents an order.
- `Customer.cs` - Represents a customer.
- `OrderRequest.cs` - Immutable request record.
- `INotifiable.cs` - Defines notification behavior.
- `Program.cs` - Creates and tests the objects.

## Topics

- Classes
- Records
- Encapsulation
- Interfaces
- Polymorphism
