# Day 4 - Collections and LINQ

## Overview

On Day 4, I worked with C# collections and used LINQ to query and process order data.

## What I Learned

- Created a list of order objects.
- Filtered data using LINQ.
- Selected and transformed values.
- Calculated aggregated results.
- Created an asynchronous method using `async` and `await`.
- Handled invalid input using exception handling.

## Topics

- `List<T>`
- LINQ filtering
- LINQ projection
- LINQ aggregation
- Async and await
- Try and catch
