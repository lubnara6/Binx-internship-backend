# Week 1 - C# Fundamentals and Git

## Overview

During Week 1, I set up my .NET development environment and practiced the core fundamentals of C# programming.

## Day 1 - Environment Setup

- Installed and verified the .NET SDK.
- Configured Visual Studio Code and the C# Dev Kit.
- Created and ran the first C# console application.
- Practiced using basic `dotnet` CLI commands.

## Day 2 - C# Fundamentals

- Practiced variables and data types.
- Learned the difference between value types and reference types.
- Used conditions, switch expressions, and loops.
- Handled nullable user input safely.

## Day 3 - Object-Oriented Programming

- Practiced classes, objects, records, and structs.
- Used properties, constructors, and access modifiers.
- Learned encapsulation, inheritance, and interfaces.
- Applied polymorphism in a small C# project.

## Day 4 - Collections and LINQ

- Worked with lists, dictionaries, and hash sets.
- Used LINQ to filter, select, and aggregate data.
- Practiced asynchronous programming with `async` and `await`.
- Used exception handling with `try` and `catch`.

## Day 5 - Git and GitHub

- Practiced the Git add, commit, and push workflow.
- Created and worked on a feature branch.
- Learned how to write clear commit messages.
- Prepared the Week 1 work for a GitHub pull request.
